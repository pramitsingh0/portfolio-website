# Technology icons

Source: [Simple Icons v16](https://github.com/simple-icons/simple-icons), downloaded from https://cdn.jsdelivr.net/npm/simple-icons@16/icons/.

SVGs are unmodified. Simple Icons is CC0-1.0; brand marks remain the property of their respective owners. The Firebase mark represents Firestore in the technology strip. Icons are decorative alongside visible technology names.

The explorer also uses CV-listed technologies from Simple Icons v16. Where a matching asset is unavailable (or a technology has no universal brand mark), a monochrome text tile is used instead of an invented logo. Google Cloud services reuse the Google Cloud mark.
